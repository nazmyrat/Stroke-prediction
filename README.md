# Прогнозирование риска инсульта

Учебный проект по анализу данных пациентов и исследованию факторов,
связанных с риском инсульта.

## Цель

Изучить данные, подготовить их для анализа и оценить,
насколько выбранная модель справляется с прогнозированием риска инсульта.

## Данные

Использован датасет: [название или ссылка на источник].

В датасете содержатся сведения о пациентах, например возраст,
наличие гипертонии и сердечных заболеваний.

## Что сделано

- Проверка и очистка данных
- Исследовательский анализ
- Визуализация признаков и их распределений
- Подготовка данных для модели
- Обучение и оценка модели
